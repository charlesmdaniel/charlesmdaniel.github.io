Projects

Structured systems for financial information and service execution.

The project layer shows how finance, accounting, operations, and systems thinking can become usable workflows. Public examples use fictional or anonymized information only.

System Flow

Collect → Analyze → Interpret → Communicate → Monitor

No public project includes real client data, private records, or performance claims.

Project 01

Wealth Management Client Analysis System

In Development

A structured financial-analysis system designed to organize client information, identify financial priorities, evaluate risks, and prepare clear planning insights.

Collect → Analyze → Interpret → Communicate → Monitor

Signal

Income, expenses, assets, liabilities, goals, holdings, and risk preferences.

Meaning

Liquidity, savings capacity, risk exposure, concentration, feasibility, and tradeoffs.

Value

Planning insights, clearer priorities, and better-prepared client conversations.

Execution

Meeting materials, action trackers, review notes, and follow-up workflows.

Potential Deliverables

  • Client Financial Profile
  • Personal Balance Sheet
  • Cash-Flow Statement
  • Financial-Ratio Analysis
  • Risk-Profile Summary
  • Goal-Priority Matrix
  • Asset-Allocation Overview
  • Client Meeting Presentation
  • Follow-Up Action Tracker

Project 02

Investment Advisory Operations Dashboard

In Development

An operational dashboard designed to track client-service workflows, documentation status, account tasks, meeting preparation, and follow-up activity.

Track → Verify → Coordinate → Report → Follow Up

Signal

Open tasks, documentation status, service requests, meeting dates, and account review needs.

Meaning

Workflow bottlenecks, missing information, priority tasks, and timing risks.

Value

Cleaner coordination, better preparation, and more consistent service follow-through.

Execution

Checklist updates, task assignment, review cadence, and reporting support.

Potential Deliverables

  • Client Onboarding Tracker
  • Document Checklist
  • Meeting Calendar
  • Action-Item Log
  • Account Review Schedule
  • Service-Request Tracker
  • Workflow Status Dashboard

Project 03

Business Science Study System

Portfolio Evidence

A self-directed learning framework integrating accounting, finance, operations, analytics, and decision science into a repeatable study system.

Read → Structure → Practice → Review → Apply

Finance

Financial analysis, time value of money, markets, risk, and investment-product concepts.

Accounting

Statements, transactions, reconciliations, reporting, and account structure.

Operations

Workflow design, process documentation, data quality, and execution control.

Analytics

Excel-based review, cleanup, validation, pattern recognition, and dashboard thinking.

Project 04

Professional Portfolio Website

Live Portfolio

A GitHub Pages portfolio designed to organize professional positioning, resume evidence, project examples, and a clear finance-and-operations framework.

Position → Structure → Publish → Validate → Improve

Input

Resume facts, project concepts, professional direction, and public site constraints.

Process

Information architecture, copywriting, semantic HTML, responsive CSS, and accessibility checks.

Output

A public portfolio that presents finance, accounting, operations, and advisory preparation.

Feedback

Future updates can incorporate new coursework, certifications, projects, and verified experience.

Resume Evidence

The projects are framed as preparation and portfolio systems.

Claims should remain tied to education, certifications, prior general experience, and clearly labeled in-development portfolio work.
